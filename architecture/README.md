# architecture/

Decisions and diagrams about *this project's own* engineering — not the pedagogical architecture diagrams shown to learners on the site (those live in `content/domains/*/diagrams` once Domain 1 content is built).

- `adr/` — Architecture Decision Records for real decisions made building this repo. New decision → copy `adr/template.md` → next number.
- `diagrams/` — source files (Mermaid `.mmd` or similar) for diagrams referenced from the "About This Project" page.
